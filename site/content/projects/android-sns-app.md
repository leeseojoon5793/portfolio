## 목적

모바일 프로그래밍 기말 과제로, 한 학기 동안 배운 안드로이드 화면 구성과 기능을 **하나의 완성된 앱**으로 묶어 보는 것이 목표였습니다. 평소 많이 쓰는 인스타그램처럼 사진을 올리고 모아 보는 앱을 주제로 정해, 실제 서비스의 기본 흐름을 직접 구현해 보고자 했습니다.

## 구현한 기능

개인 과제라 아래 기능을 모두 직접 구현했습니다. 화면은 11개입니다.

| 기능 | 내용 |
|---|---|
| 회원가입·로그인 | Firebase Authentication 이메일 계정 |
| 사진 업로드 | 갤러리에서 사진을 고르고 캡션을 붙여 게시 |
| 홈 피드 | 게시물을 목록으로 표시, 사진은 Glide로 불러옴 |
| 좋아요·댓글 | 게시물마다 좋아요 개수와 댓글 작성·조회 |
| 프로필 | 게시물·팔로워·팔로잉 수와 내 게시물 격자 보기 |
| 팔로우 | 다른 사용자 팔로우, 팔로워·팔로잉 목록 |
| 검색 | 다른 사용자 검색 | 
| 메시지 | 1:1 채팅과 채팅 목록, 새 메시지 표시 |
| 게시물 삭제 | 내 게시물 메뉴에서 삭제 |

**사용 기술:** Kotlin, Android Studio, Firebase (Authentication · Firestore · Storage), Glide, RecyclerView, ViewBinding
