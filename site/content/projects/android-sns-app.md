## 목적

모바일 프로그래밍 기말 과제로, 한 학기 동안 배운 안드로이드 화면 구성과 기능을 **하나의 완성된 앱**으로 묶어 보는 것이 목표였습니다. 평소 많이 쓰는 인스타그램처럼 사진을 올리고 모아 보는 앱을 주제로 정해, 실제 서비스의 기본 흐름을 직접 구현해 보고자 했습니다.

## 구현한 기능

개인 과제라 아래 기능을 모두 직접 구현했습니다.

| 기능 | 내용 |
|---|---|
| 로그인 | 계정으로 로그인해서 내 게시물과 활동을 구분 |
| 사진 올리기 | 갤러리에서 사진을 골라 글과 함께 게시 |
| 피드 | 올라온 게시물을 목록으로 표시 |
| 좋아요 | 게시물에 좋아요를 누르고 개수 표시 |
| 댓글 | 게시물마다 댓글 작성·조회 |
