## 안녕하세요, 이서준입니다

전북대학교에서 컴퓨터공학을 공부하고 있습니다. 수업과 팀 프로젝트에서 웹 서비스를 직접 만들고 배포하면서, 실제로 사람들이 쓰는 서비스를 만드는 개발자가 되는 것을 목표로 하고 있습니다. 
## 관심 분야

### 웹 서비스 개발

전북 지역 해커톤에서 "저녁 시간대에 문을 연 소아청소년과를 찾기 어렵다"는 지역 문제를 웹 서비스로 풀어 보면서, 공공데이터와 웹만으로도 실제 생활의 불편을 줄일 수 있다는 점이 흥미로웠습니다. 그래서 기획부터 배포까지 직접 해볼 수 있는 웹 개발에 관심을 두고 있습니다.
### AI 개발

수업 과제와 프로젝트에서 AI 도구를 직접 써 보면서, 사용하는 데서 그치지 않고 AI를 서비스 안에 넣어 활용하는 방법을 배우고 싶어졌습니다. 의료영상(PACS) 웹서비스 팀 프로젝트도 이 관심과 맞닿아 있습니다.
## 학습 목표와 실행 계획

**목표:** 이번 학기 안에 팀 프로젝트 웹 서비스를 GitHub로 협업하며 직접 배포까지 완료하기.

다음 행동:

1. 이 포트폴리오로 익힌 `Git → GitHub Actions → GitHub Pages` 배포 흐름을 팀 프로젝트에도 적용한다.
2. 작업을 작게 나눠 커밋하고, 커밋 메시지에 변경 내용을 정확히 적는다.
3. 기능을 하나 만들 때마다 이 사이트의 학습 기록에 과정과 오류 해결 내용을 정리한다.
## 사용 기술과 적용 사례

| 기술·도구 | 실제 사용 사례 |
|---|---|
| Git / GitHub | 이 사이트 저장소를 `main` 브랜치로 관리하고, 수정할 때마다 commit·push |
| GitHub Actions / Pages | push하면 Hugo로 빌드해서 GitHub Pages에 자동 배포 |
| Hugo | PaperMod 테마로 메뉴·프로필·언어 설정을 직접 구성 |
| Python Flask | 동아리 사이트 팀 저장소의 서버 스택 |
| Kotlin / Android | 모바일 프로그래밍 수업 실습 |
| C (Ubuntu) | 리눅스 프로그래밍 실습 과제 작성·제출 |
